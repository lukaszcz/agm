
## Instructions

- The AgL language reference is `reference/`; the standard-library reference is `standard-library.md`.
- Do NOT describe the details of the AgL standard library (modules, module content, exact function signatures, type defintions, etc.) in the AgL language reference. They belong in `standard-library.md`.
- The language reference MAY name a library type or function where the language's own semantics depend on it — the builtin exceptions, `ExecResult`, `ParsePolicy`, `Agent`, `AgentRequest`, `Session`, and the `std/config` engine settings — and links to `standard-library.md` for everything else.
