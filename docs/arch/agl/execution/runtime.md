# AgL Host Runtime

The runtime package is the eval-free services layer: agent dispatch and session bridging, codecs, parameter conversion, host-environment types, rendering, serialization, tracing, and the Python FFI registry. It imports neither the evaluator nor the pipeline, and it builds on AGM's shared agent and core layers rather than reimplementing them.

## Agents and Sessions

`runtime/agents.py` decodes an `Agent` member record into a host spec from `agent/spec.py` and runs the spec's argv through the shared prompt and process seam. `runtime/sessions.py` bridges AgL `Session` values to the agent session service ([agents.md](../../agents.md)), resolves an agent's default transport from its spec, and supplies a dispatcher-backed host for embeddings without a session service. Agent prompts and shell commands are text rendering, not JSON serialization. The evaluator decodes an `Agent` value to its host `AgentSpec` exactly once; `AgentRequest`, `SessionHost`, and `SessionSnapshot` all carry the decoded spec rather than the raw AgL value. `runtime/sandbox_values.py` mirrors that boundary for every `sandbox` operand (`ask`/`ask-request`, `Session::open`, `Session::default`, `exec`): it decodes an `AgentSandbox` value into `AgentSandboxMode`, a closed union (`Disabled`/`Native`/`Sandboxed`) mirroring the AgL enum, through the same identity-based member resolution `agents.py` uses; `exec`'s `Option[Sandbox]` operand decodes straight to `SandboxLimits | None` (`decode_exec_sandbox`), with no `AgentSandboxMode` in between since `exec` has no unwrapped/native distinction to select. `permission_mode_and_limits` is the one place that union becomes the `agent.spec.PermissionMode`/`sandbox.request.SandboxLimits` pair a process-preparation call site consumes. A session's sandbox is fixed once, at open (or at `Session::default`'s first use), and carried thereafter by the AgL `Session` value's own field and the session host's stored entry; `fork` copies it to the child without redecoding, and `Session.ask` never re-reads it.

## Codecs

Built-in JSON contracts consume the typeless schema and decode data compiled during lowering. `runtime/codec.py` keeps strict parsing and lenient recovery separate: agent and shell output use the configured policy, casts and `std/value::parse`/`try-parse` always parse strictly — accepting strict JSON or one [AgL value-syntax](../../agl/reference/host-environment.md#value-syntax) literal via `runtime/value_decode.py`, never lenient recovery — and `std/json` exposes both explicitly.

## Rendering and Serialization

A runtime value carries only its identity (`NominalId`/`FunctionId`) and its data — never its own display name or signature labels. All value display — interpolation, `print`, `render`, `as text`, REPL echo — goes through one renderer (`render_value`) that takes a `ValueDescriptors` view (`ir/program.py`) alongside the value, resolving a record's/exception's/constructor's spelling and a closure's param/result labels from the compiled program's own `nominals`/`functions` tables; `unit` always renders `()`. Every render call site (the evaluator, the FFI boundary, the REPL) threads the descriptor view it already holds; an FFI view a companion builds itself (`agl.array`/`agl.dict`, a nominal constructed directly) instead takes the active call's or companion import's descriptors from an ambient scoped variable ([ffi.md](ffi.md)). Nominal fields are normalized to declaration order at construction, so rendering, JSON, and equality agree without type information. Each `NominalDescriptor` also carries its `positional_fields` (`semantics.arguments.positional_field_names`), so a record/exception renders those fields bare before the rest as `name = value`. Serialization follows lowered encode plans, adding `$case` only in enum-typed slots. Encode/decode plans and JSON Schema carry each field's/member's effective JSON name (`@name`/`@json-name` if given, else declared) alongside its declared name, so JSON keys and `$case` tags can diverge from what rendering shows. An enum member's retained `@doc` additionally becomes the `description` annotation on its JSON Schema alternative. Both walks thread the shared cycle guard; trace logging and in-flight error reporting degrade cycles and non-data values to markers rather than turning a working run into a failing one.

The typeless decode schema (`ir/contracts.py`) additionally carries each field's parameter zone and `@name` alias, each record's/member's `@name` alias, each record's/enum's/member's terminal declared name, whether an enum is the standard `Agent` enum (`EnumDecode.host_agent`), and — for a field with a declared default — `default_index` (the field's position in its declaring `NominalDescriptor.fields`, never the value; `None` for a required field) — data a value-syntax reader consumes without re-deriving it from the checked types. `runtime/value_decode.py` leaves a defaulted-but-omitted field's key absent from its output, the same shape a JSON source that omits it produces; `decode_value`'s (`runtime/convert.py`) `default_resolver` callback then fills it on demand by evaluating the real `NominalDescriptor.field_defaults` entry (`IrInterpreter.default_for_field`) where an evaluator is reachable, else it is an ordinary missing-field error — resolved at decode time rather than folded at lowering, since the program's nominal table is still incomplete then. Encoding always writes every field regardless.

## Host-Backed Values and Tracing

`builtin var` bindings are identified by module, scope path, and name. Root `std/config` bindings are engine-setting registers with live effects; all others are ambient values with declared defaults that a host may seed — `std/env::environ`, for instance, is a startup snapshot of the process environment, so AgL `setenv` stays in-process. The trace store (`runtime/trace.py`) writes best-effort JSONL for run boundaries, `print`, agent requests and responses, shell executions, and escaping exceptions — never ordinary evaluation. A companion's own `runtime.trace(kind, payload)` calls ([ffi.md](ffi.md)) land in the same store as a record tagged with the extern's declaring module (`origin`) and an attributed call site (`site`/`line`/`col`, see [ffi.md](ffi.md)); unlike every other record kind, its payload is the companion's own data, so it degrades a cycle or a non-JSON value to a marker rather than failing. A write to `trace` or `trace-file` repoints it live through `runtime/host_settings.py`; `std/process::exit` propagates its `SystemExit` after the final trace record.

## Code Entry Points

- `src/agm/agl/runtime/agents.py`, `sessions.py`, `request.py`, `sandbox_values.py` — agent dispatch, session bridging, request/response types, sandbox-operand decoding.
- `src/agm/agl/runtime/codec.py`, `contract.py`, `convert.py`, `engine_config.py` — codecs, contracts, conversion, engine settings and host-value conversion.
- `src/agm/agl/runtime/render.py`, `serialize.py` — rendering and JSON serialization.
- `src/agm/agl/runtime/trace.py`, `host_settings.py`, `types.py`, `option.py` — tracing, live settings, host environment types, `Option` construction.
- `src/agm/agl/runtime/externs.py`, `boundary.py` — the FFI ([ffi.md](ffi.md)).
- Tests: `tests/test_agl_runtime.py`, `test_agl_codec.py`, `test_agl_trace.py`, `test_agl_session_runtime.py`, `test_agl_builtin_var_*.py`.
