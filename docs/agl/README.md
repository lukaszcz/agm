# AgL Documentation

AgL (Agent Language) is a small, statically checked DSL for writing agent
workflows. Its documentation is in two parts:

- **[Language reference](reference/index.md)** — the language itself: syntax,
  types, expressions, functions, modules, scopes, agent calls, shell
  execution, the FFI, exceptions, and the collected grammar.
- **[Standard library](standard-library.md)** — the `std/*` modules a program
  imports: core types, collections, data formats, environment, process, math,
  time, random, regex, paths, and filesystem APIs.
