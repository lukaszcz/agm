# AgL Evaluator

The evaluator interprets the linked program and nothing else — it never imports the frontend. A selected `program def` is invoked by its linked function symbol through the same direct-call path used by AgL calls, after module initialization but before `run()` leaves its decimal, recursion, and error boundary. `run()` invokes no entry implicitly: a host must pass the selected symbol. When that explicit symbol is the linked synthetic inline `main`, the evaluator retains its final frame and adds its direct public bindings to `RunResult.bindings`; explicit file entries report only entry-module non-function bindings. Template rendering evaluates and renders holes in order, then concatenates them with the literal chunks; the shared `%{...}` surface rules were already applied by the lexer, so no runtime template parsing happens here. Its frame stack holds `let`/param bindings directly and `var` bindings in shared cells. Before module initialization it installs the full linked parameter inventory, including params declared by imported modules. Host-provided values are installed first; omitted defaults resolve other omitted parameters on demand, so dependencies hidden behind function calls work across an import SCC without depending on module ordering. A re-entrant default dependency is reported as a parameter-cycle diagnostic. Binding is never copying: an array or dict value is a reference to a mutable payload (`ArrayValue`/`DictValue` in `semantics/values.py`), so every slot, field, capture, or iterator holding that reference observes an in-place indexed-assignment mutation. Records and exceptions are themselves immutable (no field assignment) but are likewise held and passed by reference. An enum-typed slot holds its selected member `RecordValue` directly, never an enum wrapper. The base frame is module scope, and function frames hold parameters and captured lexical bindings. Programs run under a pinned decimal arithmetic context so results never depend on the host's ambient precision.

Because binding is by reference, an indexed assignment can close a genuine reference cycle through an array or dict (never through a record/enum/exception alone — their fields are fixed at construction). `render_value`, the static JSON encoder used by normally lowered casts and scalar coercions, and `value_to_json_obj` share one active-container-id guard (`semantics/cycles.py`), converted at their call sites into the catchable `CyclicValueError`. A statically JSON-convertible growing polymorphic-recursive source uses the same encode plan as a finite one, its definitions being generic declaration templates whose type-parameter slots bind at each reference, so record-versus-enum slot context is preserved either way. The FFI encoder instead makes array and dict arguments lazy views, so cyclic arguments cross the boundary; a companion's `repr` of a view renders the cyclic value and becomes `CyclicValueError`. The interpreter routes template, print, and explicit-render calls through one render-or-raise helper; conversion and FFI boundaries retain their distinct failure policies. Equality takes the opposite approach: `values_equal` (`semantics/values.py`) is co-inductive — a container pair already being compared is assumed equal — so `==` on a cyclic value terminates and never raises.

## Control Flow

`break`/`continue`/`return` propagate as internal Python signals caught only by their owning construct (the loop, or the function-call boundary for `return`), so they unwind naturally through `try`/`catch`, which catches only AgL-level raises. An `IrCase` evaluates its subject once and selects an arm by member-record nominal or literal key; a switch with no matching key and no default is malformed IR (`InvalidIrError`) — the evaluator never synthesizes `MatchError`.

Recursion is bounded by a `max_call_depth` guard that raises a catchable `RecursionError`. Because the tree-walker spans several Python frames per AgL call, `run()` raises Python's recursion limit so the AgL guard is reached first; a Python `RecursionError` that still escapes (the limit is capped) is converted to the same catchable AgL exception (`ir_interpreter.py`). Only an escape while invoking a selected `program def` receives that entry's fallback source span; parameter setup and module initialization retain their ordinary attribution.

An `IrCase` selects nominal-member arms by the `RecordValue`'s own member-record identity (or literal keys). No tag translation participates in dispatch. `IrNominalIs` and enum-to-member identity casts compare that same identity once; a failed ordinary cast raises `CastError`, while its `as?` test form returns `false`. An `IrField` projection carries either exact nominal identity or a static upper-bound mode. The evaluator enforces identity only for exact projections; it does not name or implement any specific nominal hierarchy.

## Host-Backed Operations

Host operations are dispatched by contract identity:

- **Agents.** `ask` evaluates its `Agent` member `RecordValue`, decodes it to a host spec, and dispatches the spec's built argv through the shared agent runtime. The output is shaped by the contract's format metadata and compiled schema/decode descriptors. A unit contract dispatches once and discards the response. `AgentRequest` and agent call/parse errors retain that member `RecordValue` in their `agent` field.
- **Shell.** `exec` either returns a structured result or parses stdout into a target type, as selected during checking. A structured contract exposes a nonzero exit as data, while spawn failures and timeouts raise `ExecError`; a unit contract also raises for a nonzero exit and discards successful stdout without resolving a codec.
- **Conversions.** Casts and `parse_json` execute pre-resolved typeless recipes and always parse strictly; agent and `exec` output parsing uses the configurable strict/lenient codec pipeline.
- **Resources.** Link-resolved `IrResource` nodes evaluate to their embedded absolute `text` paths; evaluation performs no filesystem lookup.
- **Copying.** `copy` and `shallow_copy` dispatch to `semantics/copying.py`, the single shared implementation of both walks. `shallow_copy` rebuilds one container level only. `copy` recurses with an `id()`-keyed memo, so it preserves diamond sharing and is the one deep, structure-rebuilding walk in the language that terminates on a reference cycle instead of raising `CyclicValueError` — the memo resolves a re-entrant reference to the copy already under construction.

A value the host mints — a raised built-in exception, a structured `ExecResult`, an `ask-request` `AgentRequest` — takes its nominal identity from one per-program table (`ir/builtin_nominals.py`), carried on `ExecutableProgram` and built during lowering from the same shared `TypeTable` query the checker itself uses to type a host call against a program's own `builtin` declaration (`TypeTable.builtin_declarations`, `lower/lowerer.py::builtin_nominals_from_declarations`), rather than a lowering-only walk of program text — so the two can never mint/type a value against different declarations. No minting site constructs an identity of its own, so a program's declaration governs what its host-produced values are; a name the program declares nothing for answers with the shipped standard library's own reserved identity for it (`ir/reserved_nominals.py`). Every minting site also spells its `display_name` from that same table (`BuiltinNominals.resolve`, which pairs an identity with its declared spelling), so a scoped declaration reports its own spelling exactly like a source-constructed value does — `NominalId` itself is an opaque handle with no spelling of its own.

## Extern (Python FFI) Dispatch

Every callable lives in one `functions` table; a descriptor's `impl` is either an AgL body or an extern implementation naming its companion callable. An extern call is delegated to the runtime registry, which encodes arguments by their `Value` subclass, invokes Python, and decodes the returned Python representation by concrete type. The declared extern signature is a companion obligation rather than a runtime boundary contract, including parametricity. Arrays and dicts cross as lazy views without a container walk, so cyclic arguments cross. Unsupported Python representations and ordinary Python `Exception` subclasses become catchable `ExternError`; Python `BaseException` subclasses propagate. The registry imports companions after static passes succeed and before evaluation starts, making broken companions load-time diagnostics (`--dry-run` stops before import); a host capability flag gates the FFI like `supports_shell_exec` gates `exec`. The import writes no bytecode cache, because a companion may live in an installed package's immutable store tree, which must keep exactly the files its `RECORD` lists.

## Code Entry Points
