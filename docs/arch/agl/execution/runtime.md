# AgL Host Runtime

The runtime package is the eval-free services layer: agent dispatch and session bridging, codecs, parameter conversion, host-environment types, rendering, serialization, tracing, and the Python FFI registry. It imports neither the evaluator nor the pipeline, and it builds on AGM's shared agent and core layers rather than reimplementing them.

## Agents and Sessions

`runtime/agents.py` decodes an `Agent` member record into a host spec from `agent/spec.py` and runs the spec's argv through the shared prompt and process seam. `runtime/sessions.py` bridges AgL `Session` values to the agent session service ([agents.md](../../agents.md)), resolves an agent's default transport from its spec, and supplies a dispatcher-backed host for embeddings without a session service. When echo or tracing is enabled, session requests carry an output callback: backend adapters decode protocol progress separately from final response content, which remains on the normal AgL output-decoding path. Claude and Codex use their structured CLI streams; Pi's RPC backend emits text and tool progress. Each item in the `intermediate_output` array uses one `type` to identify a message, tool call, tool result, unclassified progress, or process stderr, with tool name and call ID when available. Final content remains in `content`. Echo is off by default, so untraced runs keep each agent's current command and output behavior. Agent prompts and shell commands are text rendering, not JSON serialization. The evaluator decodes an `Agent` value to its host `AgentSpec` exactly once; `AgentRequest`, `SessionHost`, and `SessionSnapshot` all carry the decoded spec rather than the raw AgL value. `runtime/sandbox_values.py` mirrors that boundary for every `sandbox` operand (`ask`/`ask-request`, `Session::open`, `Session::default`, `exec`): it decodes an `AgentSandbox` value into `AgentSandboxMode`, a closed union (`Disabled`/`Native`/`Sandboxed`) mirroring the AgL enum, through the same identity-based member resolution `agents.py` uses; `exec`'s `Option[Sandbox]` operand decodes straight to `SandboxLimits | None` (`decode_exec_sandbox`), with no `AgentSandboxMode` in between since `exec` has no unwrapped/native distinction to select. `permission_mode_and_limits` is the one place that union becomes the `agent.spec.PermissionMode`/`sandbox.request.SandboxLimits` pair a process-preparation call site consumes. A session's sandbox is fixed once, at open (or at `Session::default`'s first use), and carried thereafter by the AgL `Session` value's own field and the session host's stored entry; `fork` copies it to the child without redecoding, and `Session.ask` never re-reads it.

## Codecs

Built-in JSON contracts consume the typeless schema and decode data compiled during lowering. `runtime/codec.py` keeps strict parsing and lenient recovery separate: agent and shell output use the configured policy, casts and `std/value::parse`/`try-parse` always parse strictly — accepting strict JSON or one [AgL value-syntax](../../../agl/reference/host-environment.md#value-syntax) literal via `runtime/value_decode.py`, never lenient recovery — and `std/json` exposes both explicitly. Lenient recovery repairs JSON syntax and recognizes a unique plain-enum member tag; recovered JSON still passes through `convert.parse_json_strict`. Every host JSON/TOML decoder takes numbers through `util/decimal.parse_json_decimal` (and JSON constants through `reject_json_constant`) and maps any `ValueError` to its own parse error, so `json` values stay finite; configuration TOML reads numbers exactly through `core/toml.toml_data`, and the program-argument boundary rejects a non-finite one. An extern's `AglJson` payload is not walked: its shape and finiteness are a companion obligation. Lenient recovery is target-aware in one place: a plain-enum target whose recovered value is not a member falls back to the one member tag its text names.

## Rendering and Serialization

A runtime value carries only its identity (`NominalId`/`FunctionId`) and its data — never its own display name or signature labels. All value display — interpolation, `print`, `render`, `as text`, REPL echo — goes through one renderer (`render_value`) that takes a `ValueDescriptors` view (`ir/program.py`) alongside the value, resolving a record's/exception's/constructor's spelling and a closure's param/result labels from the compiled program's own `nominals`/`functions` tables; `unit` always renders `()`. A dict key renders through `render_key_value_syntax`: one-line value syntax, text quoted — the one key spelling, also carried in `key` by every missing-key `KeyError` (evaluator indexing, and companions via `boundary.raise_key_error`) and every `DuplicateKeyError`. Every render call site (the evaluator, the FFI boundary, the REPL) threads the descriptor view it already holds; an FFI view a companion builds itself (`agl.array`/`agl.dict`, a nominal constructed directly) instead takes the active call's or companion import's descriptors from an ambient scoped variable ([ffi.md](ffi.md)). Nominal fields are normalized to declaration order at construction, so rendering, JSON, and equality agree without type information. Each `NominalDescriptor` also carries its `positional_fields` (`semantics.arguments.positional_field_names`), so a record/exception renders those fields bare before the rest as `name = value`. An `as json` encode plan (`type_schema.build_encode_plan`) takes one of two shapes: a finite source (`TypeTable.has_finite_schema`) is planned over its canonical concrete instantiations, phantom arguments erased (`TypeTable.canonical_schema_type`); a growing one over declaration templates, each taking one argument per schema-relevant type parameter (`TypeTable.schema_relevant_params`, supplied per reference by `schema_relevant_type_args`), so phantom parameters are dropped. Plan-directed serialization uses a member tag string for a plain enum (all members fieldless, `ir/contracts.is_plain_enum`), and a `$case`-tagged object for other enum-typed slots; an exception slot's plan is a leaf, so the value encodes by its runtime nominal's `exception_field_encodes` entry. A dict's wire shape (`DictKeyForm`) — plain object, stringified-key object, or a `{"key": ..., "value": ...}` entries array — is decided by one classifier, `dict_key_form` (`ir/contracts.py`), over the key's resolved encode-schema head. Plan building (`type_schema.py`) sets `DictEncode.key_form` once per key, and schema derivation classifies the same head (`int` and `decimal` keys share one JSON-number `propertyNames` pattern, integrality left to the decoder); `key_form` is `None` iff the key is a `TypeParameterEncode` (a growing template's own key parameter; checked by `validate_ir`), the one case the encoder (`runtime/serialize.py`) classifies itself, once per dict after resolving the key. A stringified key is the key's own JSON text or enum tag. `DictDecode` carries the same `DictKeyForm` (computed by the shared `type_schema._dict_key_head_and_form`) plus a key schema; `runtime/convert.py` decodes a stringified key by turning its text into the JSON scalar it names and running the ordinary scalar/enum decode, an entries array by decoding each `key`/`value`, and builds the result through `DictValue`; two keys equal after decoding fail the conversion like any malformed input, so each conversion reports its own error. The untyped walk (`value_to_json_obj`, for values with no plan: an uncaught exception's field whose type has no JSON form) has no key or slot type: it emits a non-empty non-`text`-keyed dict as an entries array rather than collapsing distinct keys, and takes a required `WalkTags`, built once from the nominal descriptors, so it tags each enum member record with its effective `$case` (`VariantDescriptor.json_name`) and keys each record/exception field by its effective JSON name (`NominalDescriptor.field_json_names`, `ir/program.py`). Encode/decode plans and JSON Schema carry each field's/member's effective JSON name (`@name`/`@json-name` if given, else declared) alongside its declared name, so JSON keys and member tags can diverge from what rendering shows. A field's retained `@doc` becomes its JSON Schema property's `description`; an enum member's `@doc` becomes the alternative's `description`. Both walks thread the shared cycle guard; trace logging and in-flight error reporting degrade cycles and non-data values to markers rather than turning a working run into a failing one, while casts raise.

The typeless decode schema (`ir/contracts.py`) additionally carries each field's parameter zone and `@name` alias, each record's/member's `@name` alias, each record's/enum's/member's terminal declared name, whether an enum is the standard `Agent` enum (`EnumDecode.host_agent`), and — for a field with a declared default — `default_index` (the field's position in its declaring `NominalDescriptor.fields`, never the value; `None` for a required field) — data a value-syntax reader consumes without re-deriving it from the checked types. `runtime/value_decode.py` leaves a defaulted-but-omitted field's key absent from its output, the same shape a JSON source that omits it produces; `decode_value`'s (`runtime/convert.py`) `default_resolver` callback then fills it on demand by evaluating the real `NominalDescriptor.field_defaults` entry (`IrInterpreter.default_for_field`) where an evaluator is reachable, else it is an ordinary missing-field error — resolved at decode time rather than folded at lowering, since the program's nominal table is still incomplete then. Encoding always writes every field regardless.

## Host-Backed Values and Tracing

`builtin var` bindings are identified by module, scope path, and name. Root `std/config` bindings are engine-setting registers with live effects; all others are ambient values with declared defaults that a host may seed — `std/env::environ`, for instance, is a startup snapshot of the process environment, so AgL `setenv` stays in-process. The trace store (`runtime/trace.py`) writes best-effort JSONL for run boundaries, `print`, agent requests and responses, shell executions, and escaping exceptions, with source file and coordinates — never ordinary evaluation. Each `intermediate_output` item uses one `type` for message, tool call, tool result, unclassified progress, or stderr, with available tool name/call ID alongside text; final content remains in `content`. `run_start` carries supplied program arguments, host-seeded module parameters, and other host config values in addition to its invoked command and selected `program def`. Trace values are JSON-shaped; non-text-keyed dictionaries use entries arrays, enum members retain their `$case` tag, decimals use exact text strings, and cycles or non-data values degrade to markers through `runtime/serialize.py`. A companion's own `runtime.trace(kind, payload)` calls ([ffi.md](ffi.md)) land in the same store as a record tagged with the extern's declaring module (`origin`) and an attributed call site (`site`/`file`/`line`/`col`, see [ffi.md](ffi.md)); unlike every other record kind, its payload is the companion's own data, so it degrades a cycle or a non-JSON value to a marker rather than failing and records a nested mapping with any non-`str` key as an entries array; `runtime.tracing()` tells a companion whether building that payload is worth it at all. A write to `trace` or `trace-file` repoints it live through `runtime/host_settings.py`; `std/os::exit` propagates its `SystemExit` after the final trace record.

## Code Entry Points

- `src/agm/agl/runtime/agents.py`, `sessions.py`, `request.py`, `sandbox_values.py` — agent dispatch, session bridging, request/response types, sandbox-operand decoding.
- `src/agm/agent/stream.py`, `session/cli_adapters.py`, `session/rpc.py` — per-agent progress parsing and final-response separation.
- `src/agm/agl/runtime/codec.py`, `contract.py`, `convert.py`, `engine_config.py` — codecs, contracts, conversion, engine settings and host-value conversion.
- `src/agm/agl/runtime/render.py`, `serialize.py` — rendering and JSON serialization.
- `src/agm/agl/runtime/trace.py`, `host_settings.py`, `types.py`, `option.py` — tracing, live settings, host environment types, `Option` construction.
- `src/agm/agl/runtime/externs.py`, `boundary.py` — the FFI ([ffi.md](ffi.md)).
- Tests: `tests/test_agl_runtime.py`, `test_agl_codec.py`, `test_agl_trace.py`, `test_agl_session_runtime.py`, `test_agl_builtin_var_*.py`.
